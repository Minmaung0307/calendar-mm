Subscribe · 2026–2030

လက်ရှိတွင် ၂၀၂၆–၂၀၃၀ ပါဝင်သည်။ နှစ်သစ်ရောက်လည်း အရင်နှစ်ရက်များ မပျောက်ပါ။ နောက်နှစ်များကို ဆိုက်ပေါ်က မူရင်းဖိုင်တွင် ထပ်ဖြည့်တင်ပေးသောအခါ ယခု link တစ်ခုတည်းမှ Calendar app က ပြန်ယူနိုင်သည်။

Localhost တွင် public Subscribe link မရသေးပါ။ အောက်က စမ်းသပ်ရန် ဖိုင်ထုတ်ခြင်းကို သုံးနိုင်ပါသည်။ ဆိုက်ကို public HTTPS ဖြင့် တင်ပြီးမှ Subscribe လုပ်နိုင်ပါမည်။

Mac / iPhone တွင် Subscribe

Mac တွင် Location ကို iCloud ရွေးပါ။ Auto-refresh ကို နေ့စဉ်ရွေးပြီး Ignore alerts ကို အမှန်ခြစ်ပါ။

Google Calendar ကို ကွန်ပျူတာ browser မှဖွင့်ပြီး Other calendars → + → From URL တွင် Link ကို ထည့်ပါ။
