ဖုန်း Calendar ထဲ ထည့်ရန်

Calendar ထဲထည့်ခြင်းသည် အခမဲ့ဖြစ်ပြီး ငွေပေးရန် မလိုပါ။ ဤနေရာရှိ Subscription ဆိုသည်မှာ Calendar ရက်စွဲများကို ချိတ်ဆက်ရယူခြင်းသာဖြစ်ပါသည်။

iPhone / Apple Calendar နှင့် Android / Google Calendar တို့အတွက် မြန်မာရက်စွဲများကို တစ်နေကုန် event များအဖြစ် ထည့်နိုင်သည်။

ဖိုင်သည် ရွေးထားသော တစ်နှစ်စာသာဖြစ်သည်။ Import လုပ်ပြီးနောက် အလိုအလျောက် update မဖြစ်ပါ။ Calendar အသစ်တစ်ခုထဲတွင် တစ်ကြိမ်သာ ထည့်ပါ။ ထပ်ထည့်လျှင် ရက်စွဲများ ထပ်နိုင်ပါသည်။

iPhone / Apple Calendar

ဖိုင်ကို Mail attachment မှ ဖွင့်၍ Calendar ထဲ Import လုပ်နိုင်သည်။ အောက်ပါ Subscription link ရှိပါက Calendar → Calendars → Add Calendar → Add Subscription Calendar မှ ထည့်နိုင်သည်။

Apple အသုံးပြုနည်း ↗
Android / Google Calendar

ကွန်ပျူတာ browser မှ Google Calendar → Settings → Import & export → .ics ဖိုင်ရွေး → Import လုပ်ပါ။ ဖုန်းတွင် တူညီသော Google account နှင့် ဝင်ပြီး ထည့်ထားသော Calendar ကို ဖော်ပြရန် ရွေးပါ။ Google Calendar mobile app မှ တိုက်ရိုက် import မလုပ်နိုင်ပါ။

Google အသုံးပြုနည်း ↗

Subscription · 2026–2030

ရွေးထားသော တစ်နှစ်စာဖိုင်နှင့် မတူဘဲ subscription သည် ၂၀၂၆–၂၀၃၀ ပါဝင်သည်။ Website ကို public HTTPS ဖြင့် တင်ထားပြီးဖြစ်ရမည်။ ဖိုင်ကို website ပေါ်တွင် ပြန်တင်မွမ်းမံသည့်အခါ Calendar app က သူ့သတ်မှတ်ချိန်အလိုက် ပြန်ယူမည်။ ရုံးပိတ်ရက်အသစ်များကို အလိုအလျောက် ရှာမထည့်ပါ။

လက်ရှိ local / preview တွင် subscription မချိတ်နိုင်သေးပါ။ .ics ဖိုင်ကို အသုံးပြုနိုင်ပါသည်။
